# 🚀 Portofolio Belajar AI & Machine Learning

Selamat datang di repository portofolio pertama saya! Ini adalah catatan perjalanan saya dalam mempelajari Artificial Intelligence (AI), Machine Learning, dan Deep Learning secara bertahap dari nol menggunakan Python.

## 🛠️ Daftar Proyek Latihan
Repository ini berisi beberapa proyek praktis yang telah saya kembangkan:

1. **Prediksi Regresi Linear (`model_pertama.py`)**
   - Membuat model Machine Learning pertama untuk memprediksi angka/nilai berdasarkan data numerik dasar.
2. **Klasifikasi Bunga Iris - KNN (`model_canggih.py`)**
   - Membangun model klasifikasi menggunakan algoritma *K-Nearest Neighbors* (KNN) pada dataset Iris dengan tingkat akurasi mencapai **100%**.
3. **Computer Vision / Pengenalan Gambar (`deteksi_gambar.py`)**
   - Menggunakan *Random Forest Classifier* untuk melatih AI mengenali gambar angka tulisan tangan (dataset Digits) dengan akurasi **97.22%**.
4. **Deep Learning - Neural Network (`neural_network.py`)**
   - Membangun jaringan saraf tiruan (Neural Network) pertama menggunakan **PyTorch** untuk menyelesaikan logika kompleks (XOR problem).

## 🧰 Teknologi yang Digunakan
- **Bahasa Pemrograman:** Python
- **Library Utama:** NumPy, Pandas, Scikit-Learn, PyTorch
- **Tools:** VS Code, Git, GitHub
